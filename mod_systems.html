Gauss Elimination

Method Row Echelon Form (REF)

Three allowed operations (they don't change the solution set):

① Swap two rows: \(L_i \leftrightarrow L_j\)

② Multiply a row by a non-zero scalar: \(L_i \leftarrow \alpha L_i\), \(\alpha \ne 0\)

③ Add a multiple of one row to another: \(L_i \leftarrow L_i + \alpha L_j\)

Each row operation corresponds to an elementary matrix multiplied on the left. Gauss elimination is secretly computing \(A = E_1^{-1} E_2^{-1} \cdots E_k^{-1} U\) where \(U\) is upper triangular. This is the LU decomposition.

Worked Example: Complete Gauss elimination

\[\begin{pmatrix} 1 & 2 & -1 & | & 3 \\ 2 & 5 & 0 & | & 8 \\ 3 & 6 & -2 & | & 10 \end{pmatrix}\]

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - 3L_1\):

\[\begin{pmatrix} 1 & 2 & -1 & | & 3 \\ 0 & 1 & 2 & | & 2 \\ 0 & 0 & 1 & | & 1 \end{pmatrix}\]

Back-substitution: \(z = 1\), \(y = 2 - 2(1) = 0\), \(x = 3 - 2(0) + 1 = 4\).

Solution: \((x,y,z) = (4, 0, 1)\). Unique because \(\rank(A) = 3 = n\).

Worked Example: System with infinitely many solutions

\[\begin{cases} x + y - z = 2 \\ 2x + y + z = 5 \\ 3x + 2y = 7 \end{cases}\]

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - 3L_1\):

\[\begin{pmatrix} 1&1&-1&|&2 \\ 0&-1&3&|&1 \\ 0&-1&3&|&1 \end{pmatrix}\]

\(L_3 \leftarrow L_3 - L_2\):

\[\begin{pmatrix} 1&1&-1&|&2 \\ 0&-1&3&|&1 \\ 0&0&0&|&0 \end{pmatrix}\]

\(\rank(A) = 2 < n = 3\). Free variable: \(z = t\). Then \(y = 3t - 1\), \(x = 2 - y + z = 3 - 2t\).

Solution set: \(\{(3-2t,\; -1+3t,\; t) : t \in \R\} = \underbrace{(3,-1,0)}_{\text{particular}} + t\underbrace{(-2,3,1)}_{\in \Ker A}\)

Three planes in \(\R^3\). The third plane is redundant (it's the sum of the first two). The two remaining planes intersect in a line — parameterized by \(t\).

Worked Example: System with no solution

\[\begin{cases} x + y = 1 \\ x + y = 3 \end{cases}\]

\(L_2 \leftarrow L_2 - L_1\): \(\begin{pmatrix}1&1&|&1\\0&0&|&2\end{pmatrix}\)

Last row says \(0 = 2\): contradiction. \(\rank(A) = 1 \ne \rank(A|b) = 2\).

Two parallel lines in \(\R^2\) that never meet. They have the same normal direction but different offsets.

Theoretical Framework

Theorem Rouché-Capelli
\[Ax = b \text{ compatible} \iff \rank(A) = \rank(A|b)\]

When compatible, solution space dimension = \(n - \rank(A)\) = number of free variables.

Theorem Structure of Solutions
\[\text{Sol}(Ax = b) = x_0 + \Ker A\]

\(x_0\) = any particular solution. \(\Ker A\) = solution set of the homogeneous system \(Ax = 0\).

This is an affine subspace (not a vector subspace unless \(b = 0\)).

Trap Classic Mistakes

① "Rank = number of non-zero rows in echelon form" — yes, but only after complete elimination. Don't count prematurely.

② Free variables correspond to columns without pivots, not to "extra" rows.

③ If the system is homogeneous (\(b=0\)), it always has at least the trivial solution \(x = 0\). It has non-trivial solutions iff \(\rank(A) < n\).

④ Cramer's rule: only works for \(n \times n\) systems with \(\det A \ne 0\). Never use it when \(\det A = 0\).

Parametric Systems

Worked Example: System depending on parameter \(a\)

\[\begin{cases} x + ay = 1 \\ ax + y = a \end{cases} \qquad (a \in \R)\]

Matrix: \(\begin{pmatrix}1&a&|&1\\a&1&|&a\end{pmatrix}\). \(L_2 \leftarrow L_2 - aL_1\):

\[\begin{pmatrix}1&a&|&1\\0&1-a^2&|&a-a\end{pmatrix} = \begin{pmatrix}1&a&|&1\\0&1-a^2&|&0\end{pmatrix}\]

Case \(a^2 \ne 1\) (i.e., \(a \ne \pm 1\)): \(\rank = 2\), unique solution: \(y = 0\), \(x = 1\). Sol = \(\{(1, 0)\}\).

Case \(a = 1\): system becomes \(x + y = 1\) (one equation). \(\rank = 1\), sol = \(\{(1-t, t) : t \in \R\}\).

Case \(a = -1\): system becomes \(x - y = 1\) and \(-x + y = -1\) (same equation). Same as \(a=1\).

Worked Example: When does the system have solutions?

\[\begin{cases} x + y + z = 1 \\ x + 2y + 3z = 2 \\ 2x + 3y + (3+a)z = 3+b \end{cases}\]

After elimination: last row becomes \((0, 0, a \;|\; b)\).

If \(a \ne 0\): unique solution (full rank).

If \(a = 0, b = 0\): infinitely many solutions (one free variable).

If \(a = 0, b \ne 0\): no solution (\(0 = b\) contradiction).

The parameter \(a\) controls whether the third plane is "tilted" relative to the line formed by the first two planes. When \(a = 0\), the third plane becomes parallel to that line — it either contains it (\(b=0\), infinite solutions) or misses it (\(b \ne 0\), no solutions).

Applications

Application Computing \(A^{-1}\) via Gauss

Augment \((A \;|\; I)\) and row-reduce to \((I \;|\; A^{-1})\). If at any point a pivot column has no non-zero entry, \(A\) is singular.

This is more numerically stable and faster than the adjugate formula for \(n \ge 3\).

Application Least Squares (when no exact solution exists)

If \(Ax = b\) has no solution (overdetermined system, \(m > n\)), find the \(x\) that minimizes \(\|Ax - b\|^2\):

\[A^TAx = A^Tb \quad \text{(normal equations)}\]

This projects \(b\) onto \(\Im(A)\). The residual \(b - Ax\) is orthogonal to the column space.

You're finding the closest point on the "screen" (\(\Im A\)) to the target \(b\). The error vector is perpendicular to the screen. This is linear regression.
