考点速查

⚠ 最高频易错点

  • p-判别法条件反转：无穷积分 p>1 收敛，瑕积分 p<1 收敛。口诀：远严近宽。
  • Riemann 和区间误判：积分区间不一定是 [0,1]；求和上下限变了，区间也要跟着变，必要时先平移指标。
  • 极限比较法单向性：极限为 0 时只能从分母推分子（分母收敛→分子收敛），不能反推。
  • Dirichlet 条件：对振荡部分要求的是「积分有界」，而非函数本身有界。
  • 级数必要条件：∑uₙ 收敛必有 uₙ→0，但 uₙ→0 不能推出收敛。
  • 变号级数等价陷阱：等价比较优先用于正项级数；变号级数需先看绝对收敛或 Leibniz。
  • 微分方程通解结构：非齐次线性方程必须写「齐次通解 + 一个特解」，初值最后代入完整通解。
  • 子空间先看零向量：非齐次条件如 x+y=1 一定不是子空间；含“或”、绝对值的集合也要优先警惕。
  • 子空间并集：两个子空间的并集一般不是子空间，交集才是。
  • 线性映射判定要看两条：必须同时满足加法和数乘；常数项、乘积项、max、det 这类映射通常都不是线性映射。
  • det(A+B) ≠ det A + det B：行列式对行/列线性，但不对矩阵加法线性。
  • det(λA) = λⁿ det A：不要忘记 n 次方。
  • Gauss 消元看主元列：秩要在消元结束后数非零行；自由变量对应没有主元的列，不是随便挑的。
  • 非齐次解集不是子空间：Sol(Ax=b)=x₀+Ker A，通常是仿射子空间，不一定经过原点。
  • 特征多项式写法：χ_A(λ)=det(A-λI)，不是 det A-λ。
  • 特征值 λ=0 是合法的：意味着 Ker A ≠ {0}，矩阵奇异。零向量永远不是特征向量。
  • 几何重数 ≤ 代数重数：不等时矩阵不可对角化（Jordan块）。
  • 对称矩阵总可对角化：特征值全实，特征向量正交（谱定理）。
