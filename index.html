考点速查

⚠ 最高频易错点

分析

  • 原函数常数项：不定积分最后必须加 C；定积分换元后不要再加 C。
  • 分部积分选项：优先让多项式、ln、arctan 去求导；指数、三角通常留给积分。
  • 有理分式分解：不可约二次因子要配一次分子 Ax+B，不是只写常数。
  • Riemann 和步长：先提取 Δx，再识别 f(x_k)；上限是 2n 时区间常常是 [0,2]。
  • Riemann 和平移：出现 k+a 或 a+k(b-a)/n 时先找左端点，不要机械套 [0,1]。
  • p-判别条件：无穷远 p>1 收敛，0 附近瑕点 p<1 收敛，口诀是远严近宽。
  • 混合反常点：同时有 0、1、∞ 等反常点时必须拆开；全部收敛才整体收敛。
  • 等价比较前提：等价比较主要用于正项函数/级数；变号对象先看绝对值或使用 Dirichlet、Leibniz。
  • 极限比较单向性：比值极限为 0 时只能由“大者收敛”推出“小者收敛”，不能反推发散。
  • 级数必要条件：∑u_n 收敛必有 u_n→0，但 u_n→0 远远不够，例如调和级数。
  • 比值/根值 L=1：d'Alembert 或 Cauchy 得到 1 时无结论，需要换比较、等价或积分判别。
  • Leibniz 三条件：交错级数要写正项、递减、趋于 0；只说“有 (-1)^n”不够。
  • Dirichlet 条件：要求振荡部分的原函数有界，不是函数本身有界。
  • ODE 通解结构：非齐次线性方程必须写齐次通解 + 一个特解，初值最后代入完整通解。
  • 二阶重根/共振：重根要乘 x；右端与齐次解重复时特解也要乘 x。
  • 法语过程句：使用判别法前要写 On vérifie les hypothèses，不要只写 Donc converge。

线性代数

  • 子空间零向量：先检查 0 是否在集合内；x+y=1 这类非齐次条件一定不是子空间。
  • 子空间并集：交集一定是子空间，并集一般不是；除非一个包含另一个。
  • 生成族与基：生成族可以冗余，基必须同时线性无关且生成整个空间。
  • 维数公式：dim(F+G)=dim F+dim G-dim(F∩G)，不要漏掉交集。
  • 线性映射判定：必须同时满足加法和数乘；常数项、乘积项、max、det 通常破坏线性。
  • 核与像：Ker f 是定义域里的子空间，Im f 是到达空间里的子空间，别放错空间。
  • 秩-零化度：dim Ker f + dim Im f = dim E，右边是定义域维数。
  • 矩阵表示依赖基：同一个线性映射换基后矩阵会变，计算前先确认基的顺序。
  • 行列式线性误用：det(A+B) 不等于 det A + det B；det(λA)=λ^n det A。
  • 行变换与 det：交换两行变号；某行乘 λ，det 乘 λ；行加倍数不变。
  • Gauss 消元看主元：秩数非零行；自由变量对应没有主元的列。
  • 非齐次解集：Ax=b 的解集是 x0+Ker A，通常不是子空间。
  • Rouché-Capelli：有解当且仅当 rg(A)=rg(A|b)；唯一解还要等于未知数个数。
  • 特征多项式：χ_A(λ)=det(A-λI) 或 det(λI-A)，不能写 det A-λ。
  • 特征向量：λ=0 可以是特征值，但零向量永远不是特征向量。
  • 对角化判据：每个特征值的几何重数之和等于 n 才可对角化。
  • PDP⁻¹ 顺序：P 的列是 D 中对应顺序的特征向量，顺序错会导致结果错。
  • Gram-Schmidt：每一步都要减去对所有已得正交向量的投影，不是只减前一个。
